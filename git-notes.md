## GIT HAND BOOK 

1. GIT INIT - Initiates a new git repositary.

2. GIT CLONE - Lets you make a copy any codebase onto your local machine 

3. GIT STATUS - Lets you see the modifications done in the working tree 

4. GIT ADD - Lets you stage the modified files into the commit

5. GIT COMMIT - Lets you stage the changes with a simple and explanatory message with all the modifications.

6. GIT LOG - Lets you see the commit histroy of the repo.

7. GIT DIFF - Lets you see the diffrences b/w changes in the repo.

8. GIT PUSH - Lets you upload your all the local changes to the remote repository.

9. GIT PULL - Lets you pull in all the remote changes along with updating the branch.(preferred to only do when you need to update with remote changes)

10. GIT FETCH - lets you get all the remote changes without affecting the branch you're wkring in.
